# CVFuzz brand library

This is the canonical home for CVFuzz brand materials.

| Directory | Contents |
| --- | --- |
| [`logos/`](logos/) | Approved light- and dark-background logo PNGs. |
| [`assets/`](assets/) | Approved imagery used in the brand guidelines. |
| [`guidelines/`](guidelines/) | Editable HTML guide, Markdown reference, and PDF export link. |
| [`design-system/`](design-system/) | Product design-system foundations derived from the brand. |

Use `cvfuzz-logo-light.png` on white and CVFuzz Paper. Use `cvfuzz-logo-dark.png` on dark fields
and dark imagery. Do not recolor, crop, or redraw the supplied raster logo files.
